* vigcipher
Simple terminal program that applies an insecure Vigenère cipher on STDIN and send results to STDOUT

[[https://en.wikipedia.org/wiki/Vigen%C3%A8re_cipher][Vigenère cipher]]

* How to install
** Homebrew (macOS and Linux)
#+BEGIN_SRC bash
brew install redroosterkey/tap/vigcipher
#+END_SRC

** From source
You need a C compiler and make.

#+BEGIN_SRC bash
make && make test
sudo make install
#+END_SRC

This installs the =vigcipher= binary and its man page under =/usr/local=.
Set =PREFIX= to install somewhere else, for example =make install PREFIX=$HOME/.local=.
=sudo make uninstall= (with the same =PREFIX=) removes them again.

The build honours the usual =CC=, =CFLAGS=, =CPPFLAGS=, =LDFLAGS= and =DESTDIR=
variables, so it can be driven by a package manager.

* How to use
#+BEGIN_SRC bash
vigcipher --help
man vigcipher
#+END_SRC

* Development
#+BEGIN_SRC bash
